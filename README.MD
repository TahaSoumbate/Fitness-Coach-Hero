# Fitness Coach Hero Section

🔗 **[View the Live Demo Here](https://tahasoumbate.github.io/Fitness-Coach-Hero/)**

## 📸 Preview

![Profile Card Preview](./public/image/ex2.png)

A modern, high-conversion hero section for a fitness coach or personal trainer. 

## 🚀 Features
- **Floating Badges:** Uses absolute positioning to float statistics (10+ Years, 5,000+ Lives) over the image.
- **Gradient Glow Button:** Features a custom CTA button with a blurred, gradient background glow effect.
- **Stats Grid:** Highlights key metrics with clean, shadowed stat boxes.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Absolute Positioning, CSS Gradients, Pseudo-elements)

## 🧠 What I Learned
- How to use `position: relative` and `position: absolute` to place elements outside their normal flow.
- How to create a gradient glow (box-shadow) using a `::before` pseudo-element and `filter: blur()`.
- How to use Flexbox to build a responsive two-column layout.

## 📂 How to View
Simply open the `index.html` file in your browser.
